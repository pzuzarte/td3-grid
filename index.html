      TD-3 Grid help

      A pattern editor and library for the Behringer TD-3, TD-3-MO and the rest of the TD-3 family. It talks to the TD-3 over USB, and needs a current Chrome or Edge. It's unofficial and not affiliated with Behringer. Your patterns stay in your browser.

      The pattern format comes from Brad Isbell's unofficial notes on the TD-3's MIDI. His own editor is at 303patterns.com.

      Visits to this page are counted anonymously with GoatCounter, which uses no cookies. It never receives your patterns.

      Set up

      1. Connect the TD-3 to the computer with USB and turn it on. Patterns can only be sent and read over USB.
      2. Allow MIDI access when asked, including the extra access for SysEx, which patterns need. If it says MIDI blocked, click the icon to the left of the address, set MIDI devices to Allow, then click Allow MIDI.
      3. Check the TD-3 is chosen at the top. The page reads its channel from it.

      Writing a pattern

      • Notes: click a square for that note, and click it again for a rest. Drag along to draw several.
      • Key and Scale: the rows run from the key's root note at the bottom to the same note an octave up at the top, with the root rows shaded. All notes shows all 13; a mode such as Minor shows just its notes. Notes already in the pattern always keep their row. In C with All notes, the rows are the TD-3's own keys, C to the high C. With Move notes with key on, changing the key moves the whole pattern into the new key, by the nearest way up or down that fits the TD-3's range. Off, first under Key or Scale, turns the key off: the rows are the TD-3's own keys, C to the high C, all showing, with nothing shaded, and notes stay where they are. Choosing a key again, with Move notes with key on, moves each note to the nearest one in that key and mode, without changing the root. Generate needs a key.
      • Oct: moves that step's note down or up an octave from the grid, for three octaves in all. In C these are the TD-3's own Down and Up keys. In other keys, a move that would go past the TD-3's lowest or highest note is skipped.
      • Accent: plays that note louder and brighter.
      • Slide: glides from that note into the next one.
      • Step: a note, a tie, which holds the note before it for another step, or a rest. A pattern can't start with a tie.
      • Steps sets how many play, up to 16. Triplets plays them three to a beat.
      • -1 and +1 move every note a semitone, and Oct - and Oct + an octave, as far as the TD-3's range allows. Shift moves the steps round.
      • Copy (Cmd+C) and Paste (Cmd+V) above the grid work between this grid and S-1, Bass Station and Protein Grid, open in the same browser: copy a pattern in one and paste it in another. Paste replaces the grid's pattern, and Undo brings it back. Notes from the other grids land on the nearest step, up to 16; a note held past its step is tied, one that runs into the next slides, the loudest notes are accented, and where notes play together the lowest is kept. A TD-3 pattern pasted into another grid keeps its ties as longer notes, and accents as louder ones.
      • Generate writes a new acid line in the key. Undo brings back what was there.
      • Play plays the pattern on the TD-3 from this page, at the page's tempo, so you can hear it before sending it. Space starts and stops it.
      • Panic stops playback and silences any notes still sounding on the TD-3. Click plays a metronome click on each beat from this computer. Send clock sends MIDI clock, start and stop with playback. With its clock source set to USB, the TD-3 then plays its own stored pattern in time too, so turn it on only when you want that.
      • Sync plays this page together with the other grids, S-1 Grid, Protein Grid, Bass Station Grid, MPC Grid and TD-3 Grid, when they're open in the same browser, each with its MIDI connected and Sync ticked. Pressing Play or Stop on any of them starts or stops them all, from the start of their patterns, at the tempo of the page you pressed, and changing the BPM on one changes them all. The badge beside Sync shows which pages are linked. Sync starts off each time the page opens, so tick it to link the page. Song Grid arranges their patterns into a song and plays them through Sync. The Tools menu at the top opens any of them.

      The TD-3's patterns

      • The TD-3 has four groups, each with 16 patterns, A1 to A8 and B1 to B8. Choose one under On the TD-3.
      • Read loads that pattern into the grid.
      • Send writes the grid's pattern there, after asking. The page reads what was there first, so Put back can restore it, and reads it again afterwards to check it arrived.
      • Read group to library copies all 16 of a group's patterns into the library, as a backup.
      • Copy and Paste copy a pattern from one place on the TD-3 to another, even in another group, without changing the grid. Choose a place and click Copy, then choose where it goes and click Paste. As with Send, Put back restores what was there.

      Library

      • The bar at the top shows the pattern's name, large. Save (Cmd+S) saves it again: to its .syx file if it came from one or was saved as one, or to its place in the library in this browser. The first time, and with Save as… (Cmd+Shift+S), the Mac's Save dialog asks for a name and a folder, starting in the pattern folder, then in wherever you saved last. Open… opens a TD-3 .syx file from anywhere.
      • This pattern holds the grid's pattern's name. Save to library keeps it in this browser under that name, and Save to folder saves it as a file in the pattern folder. Click a pattern in either list to load it, and Send it from there.
      • Back up downloads the whole library as a file, and Import adds patterns from a backup or a .syx file. Download .syx saves the grid's pattern for the chosen place, for other SysEx tools.
      • The library is kept in this browser. Back it up now and then, as clearing the browser's data clears it.
      • Hear plays a pattern on the TD-3 without loading it into the grid. Click it again, or Stop, to stop. If the grid is already playing, the pattern takes over in time, and the grid's comes back when you stop hearing it.

      Pattern folder

      • Choose folder picks a folder on this computer that holds .syx files, such as ones downloaded from here or other TD-3 tools. Every file with a TD-3 pattern in it is listed. Chrome remembers the folder, and may ask you to allow it again after a restart.
      • Click a name to load it into the grid, or Hear to play it first. Save to folder, under This pattern, saves the grid's pattern there as a .syx file with its name. Refresh shows files added to the folder since.
      • Delete deletes the file from your computer, after asking.

      Keys

      • Space play or stop, Cmd+Z undo, Cmd+Shift+Z redo, ? this help.
